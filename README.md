# Prototipo de la home (placas NFC para restaurantes)

Prototipo de diseño para enseñar la dirección visual. No es la web definitiva: los textos son de muestra, «Vellut» es
una marca inventada y el nombre de la empresa aparece como `[MARCA]`. La página no se indexa en buscadores.

En esta versión el buscador de logos del configurador no está activo (necesita el servidor); se ve la marca de ejemplo.
